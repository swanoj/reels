# Reels

Short vertical videos (1080 × 1920) built as HTML pages and rendered to MP4 frame by frame. A reel is a folder with an `index.html` that draws any moment on request, so the same page renders identically every time and can be edited like a web page.

## Reels

- `playzone-bucks/` — "The investigation": a best man promised to sort the bucks, the group chat floods, every idea is rejected, then PlayZone Gold Coast does all of it. 60.7 s, with a deadpan documentary voiceover. `playzone-bucks?cut=30` is the 30-second ad cut of the same page.

## Render

Node.js 22 or later, and ffmpeg.

```sh
npm install
npx playwright install chromium          # once per machine
node render.mjs playzone-bucks preview 5,30,57   # stills -> out/playzone-bucks/preview-<t>.png
node render.mjs playzone-bucks                   # full video -> out/playzone-bucks.mp4, and its captions -> .srt
node render.mjs "playzone-bucks?cut=30"          # the 30-second ad -> out/playzone-bucks-cut30.mp4 and .srt
node render.mjs playzone-bucks captions          # the captions alone, in a second
```

Set `FFMPEG` if ffmpeg isn't on your PATH, and `BITRATE` to change the default 3500k. A minute of video renders in about three minutes.

## How a reel works

- `index.html` defines `window.renderFrame(t)`, which sets every element for time `t` in seconds, and `window.REEL = { fps, duration, sounds, voice, captions }`.
- A query picks another cut of the same page (`?cut=30`): the page reads it, sets its own scene list and lengths, and `render.mjs` names the output after it. Shared scenes keep one set of beats, so a fix lands in every cut.
- `captions` (optional) is a list of `{ from, to, text }` that `render.mjs` writes as SubRip (`.srt`) beside the video: each caption holds until the next when the gap is short and for at least a second, and a long one breaks onto two lines.
- `voice` (optional) is `{ file, lines: [{ at, from, to }] }`: spans of one voiceover file, each placed at `at` seconds. `render.mjs` mixes them in, dips the cues to 45% under the voice, and normalises the soundtrack to −14 LUFS for Instagram.
- `sounds` is a list of `[t, kind]` cues (`tick`, `soft`, `tock`, `pop`, `send`, `thud`, `reveal`, `swell`); `render.mjs` synthesises them into the soundtrack, so a first cut needs no sound library.
- `lib/engine.js` holds the helpers: fades, typing, counters that roll between values, scenes, film grain and the group-chat thread. `lib/icons.js` is generated by `npm run icons` from Tabler icons plus a few drawn here (bull, pool ball, pickleball, puck).

## The bucks voiceover

`playzone-bucks/voice/voiceover.mp3` is one ElevenLabs take (voice "Jack - Calm and Narrative", `JgFdKOBmiYJ6VJVKMIzb`, eleven_multilingual_v2; 742 credits, 27 September 2026) with a 1.5 s break between lines:

1. He told the boys he'd sort the bucks. He had no plan. No booking. Just... a group chat.
2. Within the hour, fourteen blokes had sent three hundred and forty-seven messages. Decisions made: zero.
3. Boat day. Done it. Paintball. Rain. A pub crawl. Six bookings. Every idea floated... was rejected.
4. Suggest. Vote. Argue. Mute the chat. Repeat. And the days kept ticking down.
5. Then someone found one place that does all of it. Dane Swan's PlayZone. Surfers Paradise.
6. A bucking bull. UV pickleball. A giant ball pit. A dunk tank. Pizza, drinks, one booking. From fifty-nine dollars a head.
7. Booked. The chat went quiet. Then it called him a legend. Case closed.
8. Bucks. Sorted.

Each scene is as long as its line needs, and its beats sit on the words: the crossed-out rows on "no plan" and "No booking", the stamps on "rejected", each node of the loop on its word, the replies on "legend", SORTED. on "Sorted." The line spans and word times come from silence detection; after a new take, measure again:

```sh
ffmpeg -i playzone-bucks/voice/voiceover.mp3 -af silencedetect=noise=-42dB:d=0.9 -f null -    # the breaks between lines
ffmpeg -ss <from> -to <to> -i playzone-bucks/voice/voiceover.mp3 -af silencedetect=noise=-38dB:d=0.12 -f null -    # the words in one line
```

## The 30-second ad cut

`?cut=30` keeps five scenes and five of the eight lines, trimmed to exactly 30.0 s: the file (line 1), the group chat (line 2, flooding faster), the breakthrough (line 5, stopping after "Dane Swan's PlayZone"; Surfers Paradise stays on the exhibit and the end card), the evidence (line 6, with the price) and the end card (line 8). It reuses the same take, so it cost no voice credits.

For a Reels or Stories ad, every scene keeps its text between 250 and 1,250 px from the top, clear of the header and of the caption and button Instagram lays over the bottom third; the ad's end card sits higher than the full reel's to do so. The price's small print is set larger and brighter than in the full reel, so "confirmed on booking" can be read on a phone.

Captions: upload `out/playzone-bucks-cut30.srt` as the video's caption file when you set up the ad, so people watching without sound can follow the voiceover. Meta may want a language tag in the file name, such as `playzone-bucks-cut30.en_GB.srt`.

## PlayZone facts in the bucks reel

Venue details and the Eat, Sip & Play prices come from the PlayZone club-proposal skill (verified September 2026): 41 Cavill Ave, Surfers Paradise; 1,000 m² over three levels; open 7 days; bucking bull, UV pickleball, giant ball pit, dunk tank, arcade, pool, table tennis and air hockey in the ticket; from $59 pp for 2 hours with pizza platters, drink cards and a reserved section. Prices change: check them at theplayzone.com.au, and that the package applies to a bucks group, before posting.

The group chat is a generic messenger look with no WhatsApp name or logo, and every name in it is invented.
