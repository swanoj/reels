# Reels

Short vertical videos (1080 × 1920) built as HTML pages and rendered to MP4 frame by frame. A reel is a folder with an `index.html` that draws any moment on request, so the same page renders identically every time and can be edited like a web page.

## Reels

- `playzone-bucks/` — "The investigation": a best man promised to sort the bucks, the group chat floods, every idea is rejected, then PlayZone Gold Coast does all of it. 58 s, first cut, sound effects only.

## Render

Node.js 22 or later, and ffmpeg.

```sh
npm install
npx playwright install chromium          # once per machine
node render.mjs playzone-bucks preview 5,30,57   # stills -> out/playzone-bucks/preview-<t>.png
node render.mjs playzone-bucks                   # full video -> out/playzone-bucks.mp4
```

Set `FFMPEG` if ffmpeg isn't on your PATH, and `BITRATE` to change the default 3500k. A minute of video renders in about three minutes.

## How a reel works

- `index.html` defines `window.renderFrame(t)`, which sets every element for time `t` in seconds, and `window.REEL = { fps, duration, sounds }`.
- `sounds` is a list of `[t, kind]` cues (`tick`, `soft`, `tock`, `pop`, `send`, `thud`, `reveal`, `swell`); `render.mjs` synthesises them into the soundtrack, so a first cut needs no sound library.
- `lib/engine.js` holds the helpers: fades, typing, counters that roll between values, scenes, film grain and the group-chat thread. `lib/icons.js` is generated by `npm run icons` from Tabler icons plus a few drawn here (bull, pool ball, pickleball, puck).
